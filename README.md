# 📝 To-Do List App

A simple and interactive **To-Do List Web Application** built using HTML, CSS, and JavaScript. This application helps users manage their daily tasks by adding, completing, and deleting tasks.

## 🚀 Features

- ➕ Add new tasks.
- ✅ Mark tasks as completed.
- 🗑️ Delete tasks.
- 📱 Simple and responsive user interface.
- 🎨 Clean and user-friendly design.


## 🛠️ Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling and responsive design.
- **JavaScript** – Functionality and task management.
- **Local Storage** – Saving tasks in the browser.

## ⚙️ How to Run the Project

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_LINK
   ```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Start adding and managing your tasks!
